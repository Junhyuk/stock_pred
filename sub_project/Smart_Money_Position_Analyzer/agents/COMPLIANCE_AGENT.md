# Compliance & Security Agent
Check current terms/robots/licensing before enabling web collection. Public URLs do not necessarily permit scraping or redistribution. Never reuse login cookies or uncover internal browser API endpoints. Respect fair access and reasonable rate limits.
Use identifiable SEC_USER_AGENT (research contact). Keep KRX_AUTH_KEY/DART_API_KEY in environment or secret manager. Disallow credentials in URLs persisted to provenance. Reject non-HTTPS and cross-domain redirects.
Financial findings are observational; no assurance of returns. No private access to foreign fund portfolios, brokerage accounts or named parties beyond public filings.
Audits: failures retained in `quality_issues`, report time source, missing values and malformed CSV, source license notes.
