# 검증 및 품질관리 계획

## 시점 정보(가장 중요)
- `event_date/as_of`: 거래일 혹은 보유현황 기준일
- `filed_at/published_at`: 외부에 공개된 날짜/시간
- `available_at`: 해당 시점 투자자가 관측 가능했던 시각(가능하면 타임존 포함)
- `ingested_at`: 프로젝트가 수집한 시각
- 백테스트는 `available_at <= simulated_decision_time`인 정보만 사용한다. 13F의 분기말 날짜를 발표 날짜로 오해하지 않는다.

## 데이터 품질 테스트
1. 시장 휴일·거래정지·시간대 차이 처리(KST, America/New_York).
2. KRX 순매수 주수 = 매수 주수 - 매도 주수, 단위 정합성 검증.
3. KRX foreign_ownership_pct ∈ [0, 100], 수량/지분율 정합성 확인(집계범위 차이는 별도 상태).
4. split/역분할, 유·무상증자, 종목코드 및 CUSIP 변경, 상장폐지 및 티커 변경 보정.
5. 13F 13F-HR/A 수정신고 중복 제거 및 신고인의 그룹·재량권 중복 집계 방지.
6. 공매도 `daily_short_volume`와 `short_interest` 별도 테이블 유지.
7. COT 선물 계약 롤오버와 만기 변경 처리.
8. 원천 데이터 날짜, 수정일, 다운로드 시각, 원본 파일 체크섬 저장.

## 성능 평가
- 라벨 추정 자체: 이후 보유율/기관 보유주수 변화와 일치율; 오분류·불확실 비율.
- 가격 예측이 목적일 경우 부가 평가: 5/20/60거래일 초과수익률, 평균/중앙 수익, 최대낙폭, 변동성, 거래비용 차감 수익, 순위 상관계수(IC), 진입 시점의 정확성.
- 단순 모멘텀, 거래량, 동일가중 매수와 비교한다. 유니버스 고정으로 발생하는 생존자 편향을 피한다.
- 검증 방식: 시간순 train/validation/test, 롤링 워크포워드, 거래비용/슬리피지, 멀티테스트 교정.

## 개발 단계
- 1단계: KRX CSV 기반 한국 수급·보유율 분석 리포트
- 2단계: SEC 13F 분기별 보유주수 변동/13D·13G 분석
- 3단계: 한국·미국 공매도/파생상품과 모순 검사
- 4단계: 수집 자동화 + 백테스트 + 예측력 정량 평가

> 외부 공개 정보만으로 특정 기관의 실제 실시간 순롱/순숏을 재구성할 수 없다. 결과는 항상 추정(간접 증거)으로 발표한다.
