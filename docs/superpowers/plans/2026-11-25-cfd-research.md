# CFD research implementation plan

Use the CFD dashboard kit’s `DATA_CONTRACT.md`, `SOURCES.md`, `TEST_PLAN.md`, and `AGENTS.md` as the specification. The research compares CFD data against the current next-session forecasting inputs and adds a domestic CFD balance chart. Python, Poppler, SQLite, XKRX, PyTorch CUDA, and the existing static dashboard supply the implementation.

## Scope and source decisions

- Use the official [KOFIA CFD disclosure archive](https://www.kofia.or.kr/brd/m_198/list.do) for domestic balances. The downloaded PDFs list the Korean name, a six-character ticker, KOSPI or KOSDAQ, disclosed CFD balance quantity in shares, and amount in units of ₩10,000. The route supplies a posting date. The amount definition’s treatment of margin and the full eligible instrument population remain unverified.
- Use source attribution and keep the raw PDFs, SQLite store, detailed symbol data and experimental results in a private ignored directory. Section 8-9(2) of the [KOFIA regulations](https://law.kofia.or.kr/service/law/lawFullScreenContent.do?historySeq=1450&seq=136) sets attribution and commercial or media use conditions. Keep recurring source requests and public numerical history behind reviewed permission that covers those operations. The public page can show official links and collection status while permission is pending.
- The [FreeSIS sitemap](https://freesis.kofia.or.kr/stats/siteMap.do) exposes distinct gross and net-of-margin CFD notional series through services `STATDRV0100000320` and `STATDRV0100000310`. The [FSC announcement](https://www.fsc.go.kr/no010101/80654) documents the national publication regime. Validate the actual downloadable data, scope, units, availability and usage terms before integrating either series. Compare each on its own definition. Treat each substitute series such as margin credit or securities lending as its own feature.

An unexpected date, duplicate ticker, invalid amount, unknown market, or table layout change rejects the document for this source definition.

## 3. Matched A/B/C evaluation

- [ ] Freeze the index panel and log its input hash and date coverage. Keep foreign closes, KRW FX and any other validated existing features available according to their own clocks. For a full-history reference, use the existing verified panel and its existing timing and provenance tags. Verify separately that recent dates used in CFD experiments have both actual target labels and stage-appropriate features.
- [ ] Join A at the historical after-close issuance from `postclose.historical_cutoff` and B/C at 08:00 KST on the target trading date, or a retained actual issuance clock if available. For historical backfill, allow a CFD observation only after midnight KST following the official posting date. Use actual receipt time and verified published time, where available, for captured replay. Keep the historical proxy evaluation and any later prospective evaluation separately scored.
- [ ] On the CFD overlap, run the same out-of-sample rows and chronological fold boundaries for a baseline and a CFD challenger. Use the latest eligible release and exact earlier exchange sessions for 1-/5-/20-session features. Prefer a small, predefined set such as the log market balance and lagged five-session relative change, with the quantity or count/coverage accounted for if explored. Fit transforms, imputation and models inside each train fold using only mature labels. Keep a fixed purge, seed, train schedule and loss across matching variants. Log the overlap removed by availability, missingness and label maturity.
- [ ] Fit A on CPU with the existing reliable linear fit. Train B and C with the local RTX 3090 on CUDA, logging the device, versions, seeds, realized date ranges and event counts. B models the next close and direction, using an anchor-adjusted regression head and the sign of the return as classification. C evaluates signed extremes with downside at or below −3%, upside at or above +3%, and the remaining range as ordinary on every eligible session. Report B’s close MAE, direction accuracy and Brier score. Report C’s all-session Brier score, tail event counts, class-specific precision and recall, and PR-AUC only where estimable. Include a no-change reference for B and a train-fold prevalence reference for C.
- [ ] Compare paired held-out metrics on the same dates and stratify where counts permit. Document the economic hypothesis that lagged changes in disclosed leverage may contain additional information, history length, coverage, collection cost, leakage checks, no-CFD ablation, and inadequate event counts. A proxy evaluation with short coverage and few extreme events supports exploration. Any production change requires a separate validation decision.
