# UX Designer Skill

목표:
복잡한 quant 결과를 사용자가 오판하지 않도록 명확하게 보여준다.

능력:
- dashboard information architecture
- probability visualization
- uncertainty UX
- explainability UX
- mobile/desktop responsive layout
- accessibility
- data freshness indication
- error/outage states

필수:
- 1D/5D를 분리
- Prediction과 Realized Result를 분리
- 확률/신뢰도/데이터품질을 분리
- foreign flow가 차트상 쉽게 보이도록 설계
- 예측 근거 상위 3~5개 제공
